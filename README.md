# tvbox-iptv

聚合国内极速直播源与 [iptv-org](https://iptv-org.github.io/) 港澳台、Nickelodeon 合集（经本地实测首段视频流连通性并按延迟排序）。

## TVBox 总节目单（含央视 / 卫视 / 香港 / 台湾 / Nickelodeon / 地方台）

- **M3U 格式（推荐）**：`https://auroragzyx.github.io/tvbox-iptv/cn_hk_tw.m3u`
- **TXT 格式**：`https://auroragzyx.github.io/tvbox-iptv/cn_hk_tw.txt`
- **JSON 配置**：`https://auroragzyx.github.io/tvbox-iptv/tvbox_live.json`

## Nickelodeon 独立合集（适合电脑 PotPlayer / VLC 或单独订阅）

- **TXT 格式**：`https://auroragzyx.github.io/tvbox-iptv/nickelodeon.txt`
