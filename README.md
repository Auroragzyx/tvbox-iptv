# tvbox-iptv

基于 [iptv-org](https://iptv-org.github.io/) 自动聚合的中国大陆、中国香港、中国台湾直播源，每日自动更新。

## TVBox 直播地址

- **M3U 格式（推荐）**：
  - GitHub Pages：`https://auroragzyx.github.io/tvbox-iptv/cn_hk_tw.m3u`
  - GitHub Raw：`https://raw.githubusercontent.com/Auroragzyx/tvbox-iptv/main/cn_hk_tw.m3u`
  - jsDelivr CDN：`https://cdn.jsdelivr.net/gh/Auroragzyx/tvbox-iptv@main/cn_hk_tw.m3u`
- **TXT 格式**：
  - GitHub Pages：`https://auroragzyx.github.io/tvbox-iptv/cn_hk_tw.txt`
  - GitHub Raw：`https://raw.githubusercontent.com/Auroragzyx/tvbox-iptv/main/cn_hk_tw.txt`
  - jsDelivr CDN：`https://cdn.jsdelivr.net/gh/Auroragzyx/tvbox-iptv@main/cn_hk_tw.txt`
- **TVBox JSON 配置**：
  - `https://auroragzyx.github.io/tvbox-iptv/tvbox_live.json`
